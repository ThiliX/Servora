# AI documentation

Filled in as the AI features are built. Nothing here is measured yet.

| Topic | Written in | Content |
|---|---|---|
| Ingestion design | M2 | Extraction, normalisation, limits, idempotency |
| Chunking and embedding profile | M2 | Chunk size, overlap, model identifier, revision, dimension |
| Retrieval settings | M3 | Top K, similarity threshold, evidence gate |
| Prompt versions | M3 | Versioned prompt text and change log |
| Evaluation dataset | M3 | Questions, expected source chunks, labelling method |
| Evaluation results | M3, M7 | Metrics with dataset, sample size, model version, thresholds and date |

## Evaluation rule

No quality figure is published without the benchmark dataset, sample size, labelling method, model version, thresholds and date. An LLM judge is never the only evaluator.
